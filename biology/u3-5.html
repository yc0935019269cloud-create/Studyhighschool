基本 1基本能力1・兩種體染色體隱性疾病

一夫妻帶有疾病 A 和疾病 B 異型合子，且兩疾病基因不連鎖，此兩遺傳疾病都是體染色體隱性疾病，則他們的第一個小孩是女孩，且同時得到此兩種疾病的機率為何？

(A) 0　(B) 1/32　(C) 1/16　(D) 3/32

看答案與詳解收起
答B。
解
  1. 夫妻都是 AaBb，兩基因不連鎖 → 分開算。
  2. 得 A 病（aa）：1/4；得 B 病（bb）：1/4。
  3. 是女孩：1/2（體染色體疾病與性別無關，所以直接乘）。
  4. 1/4 × 1/4 × 1/2 ＝ 1/32。
小結

「而且是女孩」也要乘 1/2，別漏掉。

基本 2基本能力2・紅綠色盲

人類的紅綠色盲為隱性性聯遺傳，下列相關敘述何者正確？

(A) 父親色盲，母親及外祖父母皆正常，則其兒子可能色盲　(B) 母親色盲、父親正常，則其兒子、女兒都有可能色盲　(C) 祖父色盲，此色盲性狀可藉由兒子傳到孫子　(D) 祖母色盲，此色盲性狀可藉由色盲的兒子傳給孫子

看答案與詳解收起
答A。
解

A 對：兒子的 X 來自媽媽。外祖父正常（XGY），但外祖母可能是帶因者 XGXg → 媽媽可能是帶因者 → 兒子可能色盲。

B 錯：XgXg × XGY → 女兒都拿到爸爸的 XG，只會帶因、不會色盲。

C、D 錯：爸爸傳給兒子的是 Y，不是 X。色盲基因不會「父傳子」，所以不管經過哪個兒子，都傳不到孫子（兒子的兒子）。

小結

X 性聯沒有「父 → 子」這條路。

基本 3基本能力3・體染色體隱性族譜

上圖為某兩家族的族譜，其遺傳模式為隱性體染色體遺傳，實心符號為患有疾病者，○代表正常女性，□代表正常男性。所有與此兩家族結婚者皆不含有此疾病之不正常等位基因，若 A 與 B 結婚，則他們第一胎與第二胎分別生出患有此疾病之小孩的機率為何？

(A) 1/4；1/4　(B) 1/4；1/8　(C) 1/6；1/12　(D) 1/6；1/6

看答案與詳解收起
答D。
解
  1. A（左邊家族的正常女兒）：父母正常，卻生出患病的妹妹（aa）→ 父母都是 Aa。A 表現正常，所以是 AA 或 Aa，比例 1：2 → A 為 Aa 的機率 2/3。
  2. B（右邊家族的兒子）：媽媽患病（aa），一定給 B 一個 a；B 正常 → B 一定是 Aa。
  3. 小孩患病＝A 是 Aa（2/3）× 兩人都給 a（1/4）＝1/6。
  4. 第二胎的問法相同（事前機率），每一胎都獨立計算 → 也是 1/6。
小結

「正常、但手足有病」→ 帶因機率 2/3；「媽媽有病、自己正常」→ 一定帶因。

基本 4基本能力4・試交得四種表現型

對某生物進行試交實驗，其後代出現 4 種表現型，數目為 58：60：56：61，下列 4 種基因型成員中，何者不可能是該生物之基因型（不考慮連鎖）？

(A) AaBbCc　(B) AABbCc　(C) AaBbCC　(D) AaBBCc

看答案與詳解收起
答A。
解
  1. 試交子代約 1：1：1：1，共 4 種 → 該生物剛好有 2 對異型合子（2×2＝4 種配子）。
  2. (B)(C)(D) 都只有兩對異型合子 → 可能。
  3. (A) AaBbCc 有三對異型合子 → 試交會出現 2×2×2＝8 種表現型 → 不可能。
小結

試交子代種類數＝2^(異型合子對數)。

基本 5基本能力5・雞羽毛（ZW型）

雞的羽毛呈現條紋者為顯性，無條紋者為隱性，而且此特性為性聯遺傳，若同型合子有條紋公雞和無條紋母雞交配，後代出現有條紋母雞的機會是多少？

(A) 50%　(B) 100%　(C) 37.5%　(D) 62.5%

看答案與詳解收起
答A。
解
  1. 雞是 ZW 型：公雞 ZZ、母雞 ZW。
  2. 同型合子條紋公雞 ZBZB × 無條紋母雞 ZbW。
  3. 子代：公雞 ZBZb（條紋）、母雞 ZBW（條紋），各占 1/2。
  4. 「有條紋母雞」占全部後代 50%。
小結

題目問「全部後代中」的有條紋母雞，要乘上母雞的 1/2。

基本 6基本能力6・連鎖＋試交

個體的基因型為 AaBbCc，且 A 與 b 位於同一條染色體上，若其產生配子時偶爾發生互換，則試交後子代中出現何種基因型的比例最少？

(A) Aabbcc　(B) AabbCc　(C) aaBbCc　(D) AaBbCc

看答案與詳解收起
答D。
解
  1. A 和 b 在同一條 → 另一條是 a 和 B（相斥，Ab/aB）。
  2. 親代型配子（多）：Ab、aB；重組型配子（少）：AB、ab。
  3. 試交對象給 abc，子代基因型直接反映配子：(A) Ab… 親代型；(B) Ab… 親代型；(C) aB… 親代型；(D) AB… 重組型 → 最少。
  4. C 基因在別條染色體，Cc 或 cc 各一半，不影響多少。
小結

先把同一條上的基因寫在一起，再找「和親代組合不同」的那種。

基本 7基本能力7・染色體學說（多選）

有關遺傳的染色體學說的敘述，下列哪些正確？

(A) 薩登和包法利實驗證明「基因位在染色體上」　(B) 薩登認為「一對染色體有許多控制不同性狀的基因」　(C) 減數分裂時，同源染色體可以自由組合，與孟德爾「獨立分配」相符合　(D) 受精時，每種染色體恢復雙倍數與「精卵的等位基因又成對」相符合　(E) 一對染色體有兩個基因連鎖群

看答案與詳解收起
答B、D。
解

A 錯：薩登、包法利是觀察後提出學說；用實驗證實的是摩根。

B 對。

C 錯：同源染色體是「分離」（對應分離律）；非同源染色體才自由組合（對應獨立分配律）。

基本 8基本能力8・四對基因的基因型比例（多選）

設雜交親代之基因型為 AabbCcDd × AaBbCcDd，若此四對基因均不在同一條染色體上，則雜交子代中各種基因型的比例會出現下列哪幾種？

(A) 1/16　(B) 9/16　(C) 1/64　(D) 9/64　(E) 1/128

看答案與詳解收起
答A、C、E。
解
  1. 各對分開：Aa×Aa → 1/4、1/2、1/4；bb×Bb → 1/2、1/2；Cc×Cc、Dd×Dd 同 Aa×Aa。
  2. 每個基因型比例＝四個數相乘，每個數只能是 1/4 或 1/2（bb×Bb 一定是 1/2）。
  3. 最大：1/2×1/2×1/2×1/2＝1/16（如 AaBbCcDd）。
  4. 最小：1/4×1/2×1/4×1/4＝1/128（如 AABbCCDD）。
  5. 中間：1/4×1/2×1/2×1/4＝1/64。
  6. 分子出現 9 是「顯性合併」的表現型比例，基因型不會有 → B、D 不可能。
小結

基因型比例的分子一定是 1；分子是 9、3 的是表現型。

下列各組生物染色體與性別的配合，哪些正確？

(A) 44＋XXY → 男人　(B) 6＋X → 雄果蠅　(C) 44＋X → 女人　(D) 2n → 雄工蜂（原頁此字被筆跡遮住）　(E) 22＋X → 雌蝗蟲

基本 11基本能力11・果蠅眼色性聯（多選）

若果蠅紅眼（W）對白眼（w）為顯性，今令親代為紅眼的純品系雌果蠅與白眼雄果蠅雜交，則下列有關其 F₁ 與 F₂ 之敘述，哪些正確？

基本 12基本能力12・苯丙酮尿症＋血友病（非選）

人類苯丙酮尿症是普通染色體上基因控制的隱性遺傳疾病，血友病則是 X 染色體上基因控制的隱性遺傳疾病。一對性狀表現正常的夫婦生育了一個同時患上述兩種遺傳疾病的孩子，請回答：

  1. 該患者為男孩的機率為何？
  2. 若該夫婦再生育表現正常的女兒之機率為何？
  3. 該夫婦生育的表現正常女兒，成年後與一位表現型正常的苯丙酮尿症基因攜帶男子結婚，後代中同時患上述兩種遺傳疾病的機率為何？只患一種遺傳疾病的機率為何？
看答案與詳解收起
答(1) 100%；(2) 3/8；(3) 1/48；1/4。
解

苯丙酮尿症用 A/a，血友病用 XH/Xh。孩子兩病都有 → 父母都是 Aa；爸爸正常是 XHY，所以 Xh 來自媽媽 XHXh。夫婦：AaXHY × AaXHXh。

(1) 爸爸給女兒的一定是 XH，女兒不會得血友病 → 患者一定是男孩，100%。

(2) 生女兒 1/2；女兒必不患血友病；不患苯丙酮尿症 3/4 → 1/2×3/4＝3/8。

(3) 正常女兒：Aa 的機率 2/3；XHXh 的機率 1/2。丈夫：AaXHY。

  • 小孩苯丙酮尿症：2/3×1/4＝1/6。
  • 小孩血友病：1/2（媽帶因）×1/4（生到 XhY）＝1/8。
  • 兩病都有：1/6×1/8＝1/48。
  • 只患一種：1/6×7/8＋1/8×5/6＝7/48＋5/48＝12/48＝1/4。
小結

「表現正常」的女兒要先算帶因機率（2/3、1/2），再往下一代乘。

解

科學家篩到了兩個突變株（甲和乙），其果實皆較野生型小。下列有關證實甲和乙突變為同一基因的敘述，何者正確？

(A) 若甲和乙皆為隱性同型合子，進行互交，得子代為同樣小果，則可證實　(B) 若甲和乙皆為顯性異型合子，進行互交，得子代為同樣小果，則可證實　(C) 若甲和乙皆為顯性同型合子，進行互交，得子代為同樣小果，則可證實　(D) 若甲和乙皆為隱性同型合子，進行互交，得子代果實較甲乙小，則可證實　(E) 若甲和乙皆為顯性同型合子，進行互交得子代果實較甲乙小，則可證實

看答案與詳解收起
答A。
解
  1. 甲、乙都是隱性同型合子：
  2. 若突變在同一基因：甲 aa × 乙 a′a′ → 子代 aa′，沒有正常基因 → 仍是小果。
  3. 若在不同基因：甲 aaBB × 乙 AAbb → 子代 AaBb，兩個基因都有正常版本 → 恢復野生型大果。
  4. 所以「子代仍為同樣小果」可證實同一基因 → A。
  5. 顯性突變時，子代只要帶一個突變就小果，同不同基因都一樣，無法分辨 → B、C、E 錯；D 的「更小」不是同一基因的預期。
小結

兩個隱性突變雜交，子代恢復正常 → 不同基因；仍是突變 → 同一基因。

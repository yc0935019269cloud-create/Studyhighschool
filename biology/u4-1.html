第4單元 分子生物學

4-1核酸的發現：轉形作用與噬菌體實驗

4題・經典演練2.0素養混合題1–4

先備：這一單元在找什麼

  1. 單元3說：性狀由基因決定，基因在染色體上。
  2. 染色體由兩種物質組成：蛋白質和DNA（一種核酸）。
  3. 問題來了：真正攜帶遺傳訊息的是哪一個？本篇就是科學家一步步回答這個問題的過程。
先備名詞
名詞意思本篇用在哪
遺傳物質能把性狀「指令」傳給下一代的物質全篇要找的對象
酶（酵素）只分解特定物質，例如 DNA 酶只分解 DNA艾佛瑞「拿掉一種物質」
同位素標記用帶放射性的原子當記號，追蹤物質跑到哪裡赫希與蔡司
病毒（噬菌體）只有蛋白質外殼＋核酸，必須進入細胞才能複製赫希與蔡司

核素到核酸：誰先發現

整理：發現史
年代科學家做了什麼
1869米歇爾從白血球的細胞核分離出一種大分子，命名為核素
1889阿特曼純化核素，發現它呈酸性 → 改名核酸
1920–1930多位科學家證明 DNA 都在細胞核中，是染色體的成分之一
觀念

考前提醒
- 名字的由來：在「核」裡找到 → 核素；又是「酸」→ 核酸。
- 到這一步只知道 DNA 在染色體上，還不知道它是遺傳物質；下面三個實驗才逐步證明。

格里夫茲：轉形作用

  1. 1928年，格里夫茲研究引起肺炎的肺炎雙球菌。它在培養皿上長出的菌落有兩種樣子：
整理：兩種菌
品系菌落外觀莢膜致病力
S 型光滑（smooth）有有：小鼠得肺炎死亡
R 型粗糙（rough）無無
  1. (a) 活 S 型 → 小鼠死：S 型會致病。
  2. (b) 活 R 型 → 小鼠活：R 型不會致病。
  3. (c) 熱殺死的 S 型 → 小鼠活：死菌不能繁殖，所以不會致病。
  4. (d) 熱殺 S 型＋活 R 型 → 小鼠死，血液中找到活的 S 型菌。
    原因：死的 S 型菌裡有某種物質進入活的 R 型菌，讓 R 型「變成」S 型，而且它的後代也一直是 S 型（可遺傳）。
  5. 這種「吸收外來物質而改變遺傳性狀」的現象稱為轉形作用。
觀念

考前提醒
- 格里夫茲只證明「有一種轉形物質」，沒有證明它是 DNA。
- 不是死菌復活：活的 S 型是由活的 R 型轉形來的。
- (c) 組已經有莢膜卻不致病 → 致病要靠活菌繁殖，光有莢膜不夠。

艾佛瑞：轉形物質是 DNA

  1. 1944年，艾佛瑞改在培養皿中做轉形：把熱殺 S 型菌的萃取液加入 R 型菌一起培養。
  2. 做法的關鍵：在萃取液中各加一種酶，每次只拿掉一種物質，看轉形還會不會發生。
  3. 培養後先加入「抗 R 型的血清」，讓沒轉形的 R 型菌死亡沉澱 → 盤子上若長出菌落，就是轉形成功的 S 型。
整理：只有拿掉 DNA，轉形才消失
萃取液中加入被破壞的物質S 型菌落推論
（不加酶）無有萃取液含轉形物質
RNA 酶RNA有轉形物質不是 RNA
蛋白酶蛋白質有轉形物質不是蛋白質
DNA 酶DNA無轉形物質是 DNA
觀念

考前提醒
- 判斷技巧：拿掉誰、結果就消失 → 誰就是關鍵物質。
- 只有萃取液、沒有 R 型菌的盤子「無菌落」：證明萃取液本身沒有活 S 型菌，S 型是轉形來的。

赫希與蔡司：噬菌體實驗

  1. 為什麼用噬菌體：它只由蛋白質外殼和DNA組成，感染細菌後能做出新的噬菌體 → 兩者之中必有一個是遺傳物質。
  2. 為什麼用 35S 和 32P：蛋白質含硫（S）、幾乎不含磷；DNA 含磷（P）、不含硫 → 兩種記號可以分開追蹤。
  3. 步驟：標記噬菌體 → 感染細菌 → 果汁機攪拌（把附在細菌外面的噬菌體外殼打下來）→ 離心（細菌重，沉到底；外殼輕，留在上清液）。
整理：放射性跑到哪裡
試管標記上清液（外殼）沉澱（細菌）推論
甲35S（蛋白質）有放射性無蛋白質留在細胞外
乙32P（DNA）無有放射性DNA 進入細胞
  1. 進入細菌的只有 DNA，細菌卻做出完整的新噬菌體（外殼＋DNA）→ 指揮製造的是 DNA → DNA 是遺傳物質（1952年）。
觀念

考前提醒
- 不能用 14C、3H、15N 標記：蛋白質和 DNA 都含 C、H、N，分不開。
- 口訣：「S 在上、P 在下」（硫在上清液、磷在沉澱）。

其他證據與細菌的三種重組

  1. 有絲分裂前，細胞的 DNA 先加倍，分裂時再平均分配到兩個子細胞 → 符合遺傳物質「完整複製、平分給後代」的要求。
  2. 雙套（2n）細胞的 DNA 量正好是配子（n）的兩倍 → 符合「父母各給一半」。
整理：細菌得到外來 DNA 的三條路
方式DNA 怎麼進來本篇例子
轉形作用直接吸收環境中的小段 DNAR 型菌吸收 S 型菌的 DNA
接合作用兩個細菌用性線毛連接，DNA 從一個傳到另一個—
轉導作用由噬菌體當媒介，把 DNA 帶到另一個細菌—
觀念

考前提醒
- 三種都是細菌得到新基因的方式，可以增加細菌的遺傳變異（例如抗藥性擴散）。
- 分辨：自己吸 → 轉形；牽線毛 → 接合；病毒帶 → 轉導。

經典演練：格里夫茲題組 1–4

題組敘述（92指考修訂）

光滑型（S型）肺炎球菌有莢膜且具致病性；而粗糙型（R型）肺炎球菌則無莢膜且不具致病性。格里夫茲用熱殺死的 S 型肺炎球菌注入鼠體內，鼠仍存活未受影響；但當用熱殺死的 S 型肺炎球菌和活的 R 型肺炎球菌一起注入鼠體內，則鼠罹肺炎而死，且由鼠體所分離出的肺炎球菌為 S 型。試根據格里夫茲的實驗及既有的生物學知識回答下列問題。

演練 1格里夫茲・基因型與表現型

下列有關 R 型肺炎球菌在實驗鼠中所產的子代之推論，何者正確？

(A) 表現型改變而基因型不變　(B) 基因型改變而表現型不變　(C) 表現型隨基因型的改變而改變　(D) 基因型隨表現型的改變而改變

看答案與詳解收起
答C。
解
  1. 鼠體中分離出的是 S 型，而且繼續繁殖仍是 S 型 → R 型菌的遺傳物質（基因型）被改變了，並能傳給後代。
  2. 基因型改變後，菌開始做莢膜、變得能致病 → 表現型跟著改變。
  3. 因果方向：先改基因，才改性狀。所以是「表現型隨基因型改變」，選 C；D 把因果顛倒。
  4. A 錯：若基因型沒變，後代會變回 R 型，不可能一直是 S 型。B 錯：表現型（有莢膜、致病）明顯改變了。
小結

轉形作用改的是基因型；性狀（表現型）是基因的結果，所以跟著改。

演練 2格里夫茲實驗的結論範圍

下列有關格里夫茲實驗的敘述，何者正確？

(A) 所用的 S 型肺炎球菌因具莢膜使菌體外表光滑，所以稱為光滑型　(B) 熱殺死的 S 型肺炎球菌不會使鼠致病的結果，並不能證明本菌的致病力與莢膜無關　(C) 結果證實 R 型肺炎球菌的遺傳物質可進入用熱殺死的 S 型菌體內使其復活　(D) 結果證實使 R 型肺炎球菌轉形成 S 型肺炎球菌的物質是 DNA　(E) 結果證實使 R 型肺炎球菌轉形成 S 型肺炎球菌的物質是莢膜

看答案與詳解收起
答B。
解
  1. (A) 錯：「光滑、粗糙」是指在培養皿上長出的菌落外觀（原講義也寫「菌落型態」），不是指一個菌體的表面。
  2. (B) 對：熱殺的 S 型菌雖然還有莢膜，但已經不能繁殖，所以不致病。不致病的原因可能是「死了」，而不是「莢膜沒用」→ 不能據此說致病力與莢膜無關。
  3. (C) 錯：方向反了，而且沒有復活。是 S 型菌的物質進入活的 R 型菌，使 R 型轉形。
  4. (D) 錯：格里夫茲只知道有轉形物質；證明它是 DNA 的是後來的艾佛瑞。
  5. (E) 錯：莢膜是轉形後的「結果」（性狀），不是轉形物質。

原頁沒有附這題答案；本題為單選，依上述逐項判斷只有 B 成立。

小結

格里夫茲：有轉形物質；艾佛瑞：是 DNA。死菌不會復活，是活 R 菌被改變。

演練 3莢膜與致病性（非選）

細菌的莢膜為何會有致病性？

看答案與詳解收起
答莢膜包在細菌外面，能保護細菌不被宿主的白血球吞噬（躲過免疫系統），細菌因此能在宿主體內大量繁殖而致病。
解
  1. 宿主體內有白血球會吞噬、清除入侵的細菌。
  2. 莢膜是一層包在細胞壁外的黏滑外衣，白血球不容易抓住、辨認它 → 有莢膜的 S 型菌能存活。
  3. 存活才能繁殖到很大的數量，造成肺炎 → 小鼠死亡。
  4. R 型菌沒有莢膜，很快被清除，所以不致病。
小結

莢膜本身不是毒，它讓細菌躲過吞噬、能繁殖，才致病。

演練 4轉形作用的演化意義（非選）

R 型肺炎球菌轉形成 S 型肺炎球菌在演化的意義為何？

看答案與詳解收起
答細菌可藉轉形作用從環境中取得其他個體的基因，增加族群的遺傳變異；得到有利的新性狀（如莢膜、抗藥性）的個體較能存活並留下後代，有利於族群適應環境。
解
  1. 細菌是無性生殖（分裂），子代原本和親代基因相同，變異來源少。
  2. 轉形作用讓細菌吸收別的個體的 DNA → 得到新的基因組合（遺傳變異增加）。
  3. 例：R 型得到做莢膜的基因 → 能躲過宿主免疫 → 在宿主體內存活、繁殖較多。
  4. 變異愈多，環境改變時就愈可能有個體能適應 → 對族群的生存與演化有利。
小結

轉形＝細菌的「基因交換」，增加變異，提供天擇的材料。

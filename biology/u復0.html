單元 1 這條鏈：從物質一路推到細胞怎麼複製

  1. 細胞是生物的基本單位（細胞學說）→
  2. 組成細胞的物質：水、無機鹽，以及醣類、蛋白質、脂質、核酸、維生素 →
  3. 酵素（蛋白質）負責催化細胞內的化學反應，所以反應速率受溫度、pH、受質濃度影響 →
  4. 細胞的構造：細胞膜控制物質進出，胞器各司其職（內膜系統負責分泌；粒線體、葉綠體負責能量）→
  5. 物質進出的方式：被動運輸（順梯度、不耗能）、主動運輸（逆梯度、耗 ATP）、胞吞胞吐（大分子）→
  6. 細胞分裂：有絲分裂（增生，2 個子細胞）、減數分裂（生殖，4 個、染色體減半）。

單元 2 這條鏈：能量從太陽一路到 ATP

  1. 光合作用：光能 → 化學能（ATP、NADPH）→ 醣類；
  2. 呼吸作用：醣類的化學能 → ATP（約 40% 轉成 ATP，其餘是熱）；
  3. ATP 是細胞直接使用的能量貨幣，供運輸、機械、化學三種工作；
  4. ATP／ADP 比值決定細胞走同化（合成）或異化（分解）。

規則速查（點開看「為什麼」）

下面把兩個單元最核心的規則做成卡片。外面的文字是「怎麼用」，卡片裡是「為什麼」。

一、細胞構造與運輸

細胞要記的核心是：誰有膜、誰是單層／雙層、誰含 DNA。再加上物質進出的三個判斷（要不要蛋白質？要不要能量？順還是逆梯度？）。

整理

胞器速查（膜層數）

類別 胞器 膜 重點
無膜 核糖體、中心粒 無 核糖體合成蛋白質；中心粒只有動物（含低等植物）
單層膜 內質網、高基氏體、溶體、液泡、過氧化體 單層 內膜系統（過氧化體不屬於）；溶體含水解酶
雙層膜 粒線體、葉綠體、細胞核 雙層 粒線體、葉綠體＝半自主胞器（有自己的 DNA 與核糖體）
簡單擴散（不需蛋白、順梯度）；促進性擴散（需通道／載體蛋白、順梯度）；主動運輸（需載體蛋白、逆梯度、耗 ATP）；胞吞胞吐（大分子、靠囊泡、耗能）物質進出細胞四種方式為什麼？
怎麼用
  • 判斷時依序問：①分子大還是小？大分子 ⇒ 胞吞／胞吐。②要不要蛋白質？不要 ⇒ 簡單擴散。③順梯度還是逆梯度？逆 ⇒ 主動運輸。
  • 滲透是水的擴散：水往溶質總濃度較高（高張）的一側移動。動物細胞在高張溶液中皺縮、低張溶液中膨脹破裂；植物細胞在高張溶液中質離，低張溶液中因為有細胞壁而膨脹但不破。
為什麼

磷脂雙層的內部是疏水的，只有小的非極性分子或不帶電小分子能直接穿過；帶電離子與大分子要靠蛋白質。主動運輸要逆著梯度「爬坡」，所以必須耗能（ATP）。

常見錯誤
  • 把「胞吞」當成主動運輸（它是大分子運輸，靠膜融合）。
  • 滲透方向看溶質種類，其實只看總濃度。
蛋白質分泌路徑：粗糙內質網上的核糖體 → 粗糙內質網 → 囊泡 → 高基氏體 → 囊泡 → 細胞膜（胞吐）；全程**沒有穿越**磷脂雙層分泌蛋白的旅程為什麼？
怎麼用
  • 要求「穿越幾層磷脂」：分泌蛋白＝0 層；氣體 O₂ 簡單擴散進出一次細胞膜＝2 層磷脂分子（1 次膜）。
  • 要求「哪些構造在大量分泌時發達」：核糖體、粗糙內質網、高基氏體，加上提供 ATP 的粒線體。
為什麼

囊泡由膜包住內容物，運送時與目標膜融合再釋出，蛋白質不需要直接穿膜，所以不會「穿過」磷脂雙層。

二、酵素與細胞分裂

酵素：專一性（鎖鑰）、周轉性（不消耗、可重複使用）、觸媒性（降低活化能）；影響因素：溫度（高溫變性不可逆、低溫只是活性低）、pH、受質濃度（飽和後平台）、酵素量（決定最大速率）酵素為什麼？
怎麼用
  • 溫度曲線像山丘；pH 曲線也是山丘，且每種酵素最適 pH 不同（胃蛋白酶酸性、胰蛋白酶弱鹼）。
  • 受質濃度曲線：未飽和時成正比，飽和後水平；要提高最大速率只能增加酵素量。
為什麼

酵素活性部位的立體結構要和受質吻合；高溫使蛋白質變性，結構不可逆被破壞。

常見錯誤
  • 以為低溫會「殺死」酵素（其實可恢復）。
  • 以為酵素會改變反應的方向或平衡（它只加速到達平衡）。
整理

三、光合作用與呼吸作用

光合作用：光反應（類囊體膜）：H₂O → O₂、ATP、NADPH；固碳反應（卡爾文循環，基質）：CO₂ ＋ ATP ＋ NADPH → 醣類；呼吸作用：糖解（細胞質液）→ 乙醯輔酶 A → 檸檬酸循環（基質）→ 電子傳遞鏈（內膜，需 O₂）；一分子葡萄糖約 30～32 ATP光合與呼吸為什麼？
怎麼用
  • 場所：類囊體＝光反應、基質＝固碳；細胞質液＝糖解、粒線體基質＝檸檬酸循環、內膜＝電子傳遞鏈。
  • O₂ 在哪裡：光反應產生（來自水）；呼吸電子傳遞鏈消耗（最終電子接受者）。
  • CO₂ 在哪裡：固碳反應消耗；乙醯輔酶 A 形成與檸檬酸循環釋出。
為什麼

光反應把光能存成 ATP、NADPH；固碳反應用它們把 CO₂ 還原成醣，所以固碳反應「需要化學能」，不直接需要光。呼吸作用相反，把醣的化學能搬到 ATP。

常見錯誤
  • O₂ 來自 CO₂（其實來自水）。
  • 固碳反應「一定要在黑暗中進行」（不對，只是不直接用光）。
  • 發酵在粒線體進行（發酵全程在細胞質液）。
整理

C₃、C₄、CAM：C₃＝只有卡爾文循環，氣孔白天開；C₄＝空間隔離（葉肉先固定成四碳酸，維管束鞘做卡爾文循環）；CAM＝時間隔離（夜間開氣孔固定 CO₂ 成四碳酸儲存液泡，白天釋出進卡爾文循環）。最終都要經過卡爾文循環（C₃ 途徑）。

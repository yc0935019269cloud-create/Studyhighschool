第3單元 遺傳學

3-4基因的連鎖與互換：重組率與遺傳圖譜

4組練習・涵蓋經典演練2.0素養混合題1–4

摩根與果蠅

  1. 摩根用果蠅推出白眼基因在X染色體上（性聯遺傳，見3-3）；後來又證明體染色體上的基因也會連鎖。
  2. 用的是黑腹果蠅：好取得、好養、世代短（約10～14天）、後代多、操作簡單。
  3. 染色體只有4對（含1對性染色體），顯微鏡下容易觀察。
觀念

考前提醒
- 「連鎖」＝兩個基因在同一條染色體上，減數分裂時傾向一起進入同一個配子。
- 連鎖群數＝染色體對數：果蠅4群（雌），人類女性23群。

果蠅試交的三種可能結果

  1. 灰身（B）對黑身（b）為顯性；長翅（V）對殘翅（v）為顯性。
  2. 灰身長翅（BBVV）× 黑身殘翅（bbvv）→ F₁ 全為 BbVv（灰身長翅）。
  3. 再拿 F₁ 和 bbvv 試交：試交對象只給 bv，所以子代表現型＝F₁ 配子種類。
整理：三種假設、三種答案
假設F₁ 配子灰長：黑長：灰殘：黑殘
① 不連鎖（不同染色體）BV、bV、Bv、bv 各1/41：1：1：1（四種）
② 連鎖、完全不互換只有 BV、bv1：0：0：1（只有兩種）
③ 連鎖、重組率20%BV、bv 各40%；bV、Bv 各10%4：1：1：4（四種，兩多兩少）
觀念

考前提醒
- 出現四種表現型不代表不連鎖；要看比例是不是 1:1:1:1。
- 「兩多兩少」→ 多的那兩種是親代型，少的那兩種是重組型。

摩根的實驗結果與推論

  1. 結果：灰長 965、黑殘 944（親代型，多）；灰殘 206、黑長 185（重組型，少）。
  2. 不是 1:1:1:1（不像獨立分配），也不是只有兩種（不像完全連鎖）。
  3. 推論①：體色和翅長基因在同一條染色體上，通常一起進入同一配子（同一連鎖群）。
  4. 推論②：減數分裂聯會時，同源染色體可能互換一段，產生新組合；比例較低的子代就是互換造成的。
整理：算一次
個體數
親代型（灰長＋黑殘）965＋944＝1909
重組型（灰殘＋黑長）206＋185＝391
總數2300
重組率391÷2300≈17%
觀念

考前提醒
- 講義說「4:4:1:1」是取整數的大概比例；實際算出約17%，下一頁圖的另一組數據才是剛好20%。
- 若各樣本數都是期望值 575，就代表獨立分配；差這麼多絕不是取樣誤差。

連鎖與互換：用試交判斷

  1. 判斷兩基因有沒有連鎖、有沒有互換：拿異型合子當親代做試交。
  2. 沒互換的染色體 → 親代型配子；有互換的染色體 → 重組型配子。
觀念

考前提醒
- 哪兩種算「親代型」要看 F₁ 從哪兩個親代拿到哪兩條染色體。
- BV/bv（相引）：重組型是 Bv、bV；Bv/bV（相斥）：重組型反過來是 BV、bv。題目常故意給相斥型。

重組率

  1. 重組率：發生互換（重組）的配子占全部配子的百分比。
  2. 試交時重組型配子 → 直接變成重組型子代，所以可用子代個體數來算。
  3. 重組率最大 50%：就算每個生殖母細胞都互換，四個配子中也只有兩個是重組型。
整理：互換的特性
特性結果
兩基因相距愈遠中間愈容易發生互換 → 重組率愈高（正相關）
同源染色體可在幾個部位同時互換相距很遠的兩基因重組率會趨近 50%，看起來像獨立分配

遺傳圖譜與分摩根

  1. 史提曼以短臂（p）末端為 0，用重組率標出各基因在染色體上的相對位置與順序，就是遺傳圖譜。
  2. 單位：重組率 1% ＝ 1 分摩根（cM）。
  3. 某基因在遺傳圖譜上的位置稱為基因座。
觀念

考前提醒
- 遺傳圖譜是「相對距離」，不是用尺量的實際長度。
- 「相距 20 個互換單位」＝重組率 20%：兩種重組型配子各 10%，兩種親代型配子各 40%。

素養混合題：突變果蠅

  1. a（黑身）、b（短翅）在同一條體染色體上 → 連鎖，要用重組率。
  2. d（白眼）在X染色體上 → 性聯，寫基因型時要寫成 XD、Xd、Y。
  3. 眼色跟 a、b 在不同染色體上 → 和它們獨立，可以分開算再相乘。
練習 1素養混合題1・只看眼色

若只研究眼色，不考慮其他性狀，則白眼雌果蠅與紅眼雄果蠅雜交，F₁ 雌、雄果蠅的表現型及其比例為何？

看答案與詳解收起
答F₁ 雌果蠅全為紅眼；雄果蠅全為白眼（雌紅眼：雄白眼＝1：1）。
解
  1. 先寫親代：白眼雌 XdXd；紅眼雄 XDY。
  2. 雌配子只有 Xd；雄配子 XD、Y 各一半。
  3. 女兒＝Xd（媽）＋XD（爸）＝XDXd → 紅眼。
  4. 兒子＝Xd（媽）＋Y（爸）＝XdY → 白眼。
小結

性聯題先寫 X、Y：爸爸的 X 只給女兒，兒子的 X 只來自媽媽。

練習 2素養混合題2・反交

承上題，若以同表徵之純種親代互交（即紅眼純種雌 × 白眼雄），則 F₁ 雌雄果蠅的表現型及其比例為何？

看答案與詳解收起
答F₁ 雌、雄果蠅全為紅眼。
解
  1. 互交＝把雌雄的性狀對調：紅眼純種雌 XDXD × 白眼雄 XdY。
  2. 女兒 XDXd → 紅眼；兒子 XDY → 紅眼。
  3. 和第1題結果不同 → 這正是判斷「性聯遺傳」的方法：正交、反交結果不同。體染色體遺傳正反交結果相同。
小結

正交反交結果不一樣，就是性聯的訊號。

練習 3素養混合題3・體色＋眼色

基因型為 aaXdXd 和 AaXDY 的果蠅雜交，F₁ 果蠅的基因型及其比例為何？

看答案與詳解收起
答AaXDXd：aaXDXd：AaXdY：aaXdY＝1：1：1：1。
解
  1. A 在體染色體、D 在 X 染色體 → 兩者獨立，分開算。
  2. aa × Aa → Aa：aa＝1：1。
  3. XdXd × XDY → XDXd（雌）：XdY（雄）＝1：1。
  4. 相乘：四種各 1/2×1/2＝1/4。
XDXd（1/2）XdY（1/2）
Aa（1/2）AaXDXd 1/4AaXdY 1/4
aa（1/2）aaXDXd 1/4aaXdY 1/4
小結

不同染色體上的基因：各自算比例，再做表相乘。

練習 4素養混合題4・重組率＋性聯（單選）

若基因 a 和 b 的重組率為 10%，現有黑身短翅白眼的雌果蠅與正常純種雄果蠅雜交得到 F₁，F₁ 雌果蠅所產生的卵基因型為 AbXD 和 AbY 之機率各是多少？

(A) 1/20，0　(B) 1/40，0　(C) 1/20，1/20　(D) 1/40，1/40

看答案與詳解收起
答B。
解
  1. 親代：雌 aabbXdXd（給 ab、Xd）；雄 AABBXDY（給 AB，XD 或 Y）。
  2. F₁ 雌＝XDXd，體染色體一條是 AB、一條是 ab（相引）。
  3. a、b 重組率 10% → 重組型配子 Ab、aB 各 5%；親代型 AB、ab 各 45%。
  4. Ab 的機率 5%＝1/20；卵拿到 XD 的機率 1/2 → AbXD＝1/20×1/2＝1/40。
  5. 卵細胞來自雌果蠅（XX），不可能帶 Y → AbY＝0。
小結

重組率要「除以2」才是單一種重組配子的機率；雌配子絕不帶 Y。

本單元整理

整理
題目線索先做的事常見誤判
試交子代 1:1:1:1不連鎖（或相距極遠）—
試交子代只有兩種、1:1完全連鎖以為是單基因
試交子代兩多兩少連鎖＋互換；少的兩種是重組型看到四種就說不連鎖
算重組率重組型個體數 ÷ 總數只拿一種重組型去除
給重組率求配子重組型各「一半」、親代型各「(100−重組率)÷2」忘了先判斷相引或相斥
連鎖＋性聯體染色體部分與 X 部分分開算，再相乘讓卵帶 Y

第4單元 大氣

4-3風向與風速：氣壓梯度力、科氏力與摩擦力

9題・原講義小試身手1–9

風與三種水平作用力

  1. 空氣受外力作用而運動，就是風。
  2. 垂直方向：氣壓梯度力（往上）與重力大致平衡，所以大氣不容易有劇烈的垂直運動。
  3. 本單元說的「風」都是水平方向，受三種力影響：氣壓梯度力、科氏力、摩擦力。
整理：三種力各管什麼
力影響風向影響風速方向
氣壓梯度力✓✓垂直等壓線，高壓 → 低壓
科氏力✓✗垂直風向；北半球在右、南半球在左
摩擦力間接✓與風向相反

氣壓梯度力

  1. 風向：空氣被氣壓梯度力推著，由高壓流向低壓。
  2. 風速：單位距離內氣壓差愈大（等壓線愈密），氣壓梯度力愈大，風速愈快。
  3. 方向恆垂直等壓線，由高壓指向低壓。

科氏力

  1. 地球自轉，使運動中的物體相對地面往右或往左偏移；造成偏移的「力」叫科氏力，是一種假想力。
  2. 緯度愈高，科氏力愈大：兩極最大、赤道為 0。
  3. 風速愈快，科氏力愈大；空氣靜止就沒有科氏力。
  4. 科氏力永遠和風向垂直：北半球指向運動方向的右方，南半球指向左方。
觀念

考前提醒
- 科氏力和運動方向垂直 → 只改變風向，不改變風速。
- 赤道附近科氏力 ≈ 0，所以颱風不會在赤道上生成。

摩擦力

  1. 近地面的風受地表摩擦而變慢。
  2. 風速變慢 → 科氏力變小 → 偏轉角度變小（間接影響風向）。
  3. 摩擦力方向與風向相反。

地轉風與近地面的風

整理：地轉風 vs 近地面的風（北半球）
地轉風近地面的風
位置高空（約1公里以上），摩擦力很小近地表
受力氣壓梯度力、科氏力氣壓梯度力、科氏力、摩擦力
形成過程空氣加速 → 科氏力漸增 → 往右偏轉 90°，氣壓梯度力＝科氏力（方向相反）摩擦使風速低，科氏力不夠大，偏不到 90°
風向平行等壓線斜穿等壓線、偏向低壓，夾角 θ 一般不超過 30°
觀念

考前提醒
- 摩擦力愈大 → 風速愈慢 → 科氏力愈小 → 夾角 θ 愈大：陸地上的 θ 比海洋大。
- 白貝羅定律（背風而立，北半球高壓在右、低壓在左）在海上、高空最準，陸地上因摩擦會有誤差。

三步驟判斷風向

  1. 找出該點附近兩條等壓線的走向。
  2. 畫氣壓梯度力：垂直等壓線，由高壓指向低壓。
  3. 北半球往右偏：地轉風偏 90°（平行等壓線）；地面風偏約 60～75°（和等壓線夾 15～30°）。
觀念

考前提醒
- 風向是「從哪裡吹來」：往西南吹的風叫東北風。
- 南半球三步驟相同，只是第 3 步改成往左偏。

高壓與低壓

整理
高壓（反氣旋）低壓（氣旋）
地面氣流輻散：北半球順時針旋出；南半球逆時針輻合：北半球逆時針旋入；南半球順時針
中心垂直氣流下沉（高空輻合）上升（高空輻散）
天氣下沉增溫、不易飽和 → 晴朗上升降溫、容易飽和 → 雲雨
觀念

口訣：右手法則
- 大拇指＝垂直氣流（朝上＝上升、朝下＝下沉），四指彎曲方向＝旋轉方向。
- 北半球用右手、南半球用左手。例：南半球高壓 → 左手、拇指朝下 → 四指是逆時針。

請問臺灣大致吹什麼風？

(A) 東北風　(B) 東南風　(C) 西南風　(D) 西北風　(E) 南風

看答案與詳解收起
答A。
解
  1. 1 月，大陸冷高壓在西北、海上低壓在東方 → 臺灣附近等壓線大致呈東北—西南走向。
  2. 氣壓梯度力：由西北（高壓）指向東南（低壓）。
  3. 北半球地面風往右偏 60～75° → 往西南吹 → 從東北吹來 ＝ 東北風（冬季東北季風）。

小試 2混合題・梯度力最大、風速最快

請問 A～D 何處氣壓梯度力最大？何處風速最快？

選項(A)(B)(C)(D)(E)
梯度力最大ADADB
風速最快ADDAB
看答案與詳解收起
答A。
解
  1. 氣壓梯度力看等壓線疏密：A 位在東北角，等壓線最密 → 梯度力最大。
  2. 風速主要由梯度力決定；A 又在海面附近，摩擦力小 → 風速也最快。
  3. D 雖在海上（摩擦小），但等壓線稀疏，梯度力小，風不會比 A 快。
小結

風速：先看等壓線疏密，再看摩擦（陸地慢、海上快）。

小試 3混合題・畫出 D 的風向與三力

請在圖中畫出 D（菲律賓東方海上）之風向與造成此風向之三力方向（氣壓梯度力標 p、科氏力標 c、摩擦力標 f）。

看答案與詳解收起
答p 指向東南（垂直等壓線、指向低壓）；風往西南吹（東北風），與等壓線夾一小角度偏向低壓；c 垂直風向、指向風的右方（西北）；f 與風向相反（指向東北）。
解
  1. D 附近等壓線呈西南—東北走向，高壓在西北（大陸），所以 p 往東南。
  2. 北半球往右偏、但有摩擦偏不到 90° → 風往西南吹，斜穿等壓線、略偏向低壓一側。
  3. c 永遠垂直風向、在風的右邊 → 指向西北。
  4. f 永遠和風向相反 → 指向東北。
  5. 檢查：c 與 f 的合力剛好和 p 平衡（反向），三力平衡風才會穩定吹。
小結

畫三力：p 垂直等壓線指低壓；c 在風的右邊垂直；f 與風相反。

小試 4混合題・陸地上的夾角

C 處位於內陸，D 處位於海洋，已知風吹過陸面所受到的摩擦力較海面大，則 C 處風向為何？且風向與等壓線的夾角會較 D 處風向與等壓線的夾角大或小？

(A) 西北風、較大　(B) 東南風、較大　(C) 西北風、較小　(D) 東南風、較小　(E) 西風、較大

看答案與詳解收起
答B。
解
  1. C 附近等壓線大致呈西北—東南走向，高壓在 C 的東北方（大陸高壓）→ 梯度力指向西南。
  2. 北半球往右偏（小於 90°）→ 風往西北偏西吹 → 從東南吹來 ＝ 東南風。
  3. 陸地摩擦大 → 風速慢 → 科氏力小 → 偏得少 → 與等壓線的夾角較大。
小結

摩擦愈大，風愈「直直衝向低壓」，夾角愈大。

小試 5學測・摩擦力的影響

如果在赤道以外的地方考慮近地面的風，由於流動的空氣與地面有摩擦力，則下列哪一項敘述是正確的？

(A) 摩擦力使風速降低，科氏力隨之減小　(B) 摩擦力使風速降低，科氏力隨之增大　(C) 摩擦力對風速沒影響，但對科氏力影響很大　(D) 摩擦力對科氏力沒影響，但對風速影響很大　(E) 摩擦力對風速和科氏力都沒有影響

看答案與詳解收起
答A。
解

摩擦力與風向相反 → 風速變慢；科氏力大小和風速成正比 → 科氏力也變小。這就是摩擦力「間接」影響風向的原因。

小結

摩擦 → 風慢 → 科氏力小 → 偏轉少。

小試 6學測・由高空北風推地面風

氣壓梯度力和科氏力平衡時所吹的風稱為地轉風。北半球某地高空的地轉風是吹北風，假設從地面到高空的等壓線分布型態不變，則地面風最有可能吹什麼風？

(A) 北風　(B) 東風　(C) 西南西風　(D) 東北東風　(E) 北北西風

看答案與詳解收起
答E。
解
  1. 高空吹北風 → 空氣往南走，等壓線呈南北走向。
  2. 北半球地轉風：背風而立，低壓在左。面向南方時左手邊是東 → 東邊低壓、西邊高壓 → 梯度力指向東。
  3. 地面風：從梯度力（往東）往右偏約 60～75° → 往南南東吹 → 從北北西吹來。
  4. 也可以這樣想：地面風比地轉風「再偏向低壓一點」→ 北風稍微偏向東邊的低壓 → 北北西風。
小結

地面風＝地轉風往低壓側轉 15～30°。

小試 7判讀地面天氣圖（應選2項）

附圖為某地的地面天氣圖，甲、乙、丙為高壓或低壓中心，箭頭為標示地之風向，下列敘述哪些正確？

(A) 附圖位於北半球　(B) 甲地有下沉氣流　(C) 乙地多為陰雨天　(D) 丙地多為晴朗的天氣　(E) 乙地東側箭頭處的風速比西側箭頭處的風速快

原圖中甲、乙、丙旁的 H、L 是手寫筆記，先別看，自己推。

看答案與詳解收起
答B、C。
解
  1. 先看甲：甲西側的風往南（略偏外）吹。若甲是高壓、北半球應順時針 → 西側應往北吹，不合；南半球高壓逆時針 → 西側往南吹 ✓。所以這是南半球，甲是高壓（A 錯）。
  2. 乙：東側風往西南吹進乙、西側往東北吹進乙 → 氣流向內、順時針 → 南半球的低壓。丙：東側往南吹，也是順時針 → 低壓。
  3. B：甲是高壓，中心下沉 ✓。
  4. C：乙是低壓，上升氣流 → 多陰雨 ✓。
  5. D：丙也是低壓，不會「多為晴朗」✗。
  6. E：乙西側等壓線比東側密 → 西側風較快 ✗。
小結

判斷半球：看高（或低）壓周圍氣流是順時針還是逆時針。

小試 8冷熱造成的氣壓差（熱力環流）

假設附圖為溫度不同所導致甲、乙兩地氣壓差異之垂直等壓線分布圖：甲地上方的等壓面間距較大、往乙地逐漸收攏；最低一條等壓面在甲地較低、在乙地較高。關於兩地之敘述何者正確？

(A) 甲地近地面氣壓較高　(B) 乙地近地面氣溫較高　(C) 地面空氣為甲吹向乙　(D) 乙地應有垂直下沉氣流　(E) 甲地近地面附近空氣密度較高

看答案與詳解收起
答D。
解
  1. 等壓面間距大 → 氣柱受熱膨脹 → 甲地較熱，乙地較冷。
  2. 近地面：最低的等壓面在乙地比較高 → 同一高度乙的氣壓較大 → 乙地面高壓、甲地面低壓（A 錯）。
  3. B 錯：乙較冷。E 錯：甲熱空氣密度較小。
  4. C 錯：地面風由高壓吹向低壓 → 由乙吹向甲。
  5. D 對：乙地面高壓 → 中心下沉；甲則上升，形成熱力環流。
小結

地面：熱 → 低壓、上升；冷 → 高壓、下沉。（高空則相反）

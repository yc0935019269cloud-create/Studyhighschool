水氣的飽和與相變

  1. 溫度愈高的空氣，可容納的水氣愈多，即飽和水氣壓愈高。
  2. 原圖橫軸溫度、縱軸水氣壓；中間那條往右上彎的是飽和曲線。
  3. 曲線右下方：未飽和區（實際水氣壓＜飽和水氣壓）。
  4. 曲線左上方：過飽和區（水氣通常已開始凝結，不會持續停留）。
{{FIG_saturation}}
整理
要使未飽和空氣達飽和做法
(a) 增加水氣讓實際水氣壓升高到等於飽和水氣壓
(b) 降低溫度讓飽和水氣壓降到等於實際水氣壓（自然界主要走這條路）
觀念

考前提醒
- 降溫達飽和，不一定凝結成水滴，低溫時也可能直接凝華成冰晶。
- 過飽和區只是理論位置，自然界水氣一達飽和通常就相變，不會停在那裡。

露點與相對溼度

  1. 露點溫度：水氣壓不變，純降溫使空氣達飽和，此時的溫度。
  2. 露點只由實際水氣壓決定，跟當下氣溫無關。
  3. 兩團空氣只要實際水氣壓相同，露點就相同（即使氣溫差很多）。

整理：公式怎麼用
例題算法
A：31°C，實際水氣壓21 hPa，同溫飽和水氣壓42 hPa21÷42×100%＝50%
D：40°C，實際水氣壓21 hPa，同溫飽和水氣壓60 hPa21÷60×100%≈35%
觀念

考前提醒
- A、D水氣壓都21 hPa、露點都約17°C，但相對溼度不同（50% vs 35%）——水氣壓相同只保證露點相同，不保證相對溼度相同，分母還要看各自氣溫。
- 氣溫相同時，實際水氣壓愈高、氣溫與露點差距愈小，相對溼度愈高。

乾溼球溫度計

  1. 乾球：量當時氣溫。
  2. 溼球：紗布上的水蒸發吸熱，使讀數低於乾球。
  3. 環境愈乾燥 → 蒸發愈多 → 吸熱愈多 → 溼球愈低 → 乾溼溫差愈大。
{{FIG_wetdry}}
整理
空氣狀態三個溫度的關係
水氣已飽和乾球＝溼球＝露點
水氣未飽和乾球 ＞ 溼球 ＞ 露點
觀念

考前提醒
- 蒸發一定吸熱，溼球不可能比乾球高。
- 查表法：先鎖定「乾球溫度那一列」，再找相對溼度對應的差值欄位，乾球減差值＝溼球。

雲、霧、露、霜

  1. 成因相同：空氣冷卻達飽和、水氣凝結或凝固。
  2. 高空發生 → 雲；接近地面或海面 → 霧。
  3. 附著物體表面，液態 → 露；固態 → 霜。
  4. 需要凝結核：乾淨空氣即使飽和也難凝結，靠氣膠等微粒讓水氣分子聚集。

絕熱冷卻

  1. 空氣是熱的不良導體 → 垂直運動時可視為絕熱（與外界無熱量交換）。
  2. 上升：外界氣壓變小 → 空氣塊膨脹 → 對外作功 → 耗內能 → 降溫。
  3. 下沉：外界氣壓變大 → 空氣塊壓縮 → 外界對它作功 → 內能增 → 升溫。
觀念

考前提醒
- 爬山愈高愈冷，不是摸到山頂原本就冷的空氣，是空氣塊自己絕熱膨脹冷卻。
- 上升→膨脹→降溫→容易成雲；下沉→壓縮→升溫→多半晴朗。

降溫速率原因
①乾絕熱（未飽和）約10°C/km，先讀這條純膨脹作功，無潛熱釋放
②溼絕熱（已飽和）約4–6°C/km，較慢水氣凝結釋放潛熱，部分抵銷降溫
  1. 同一空氣塊：未飽和先走①（較陡），達飽和後轉走②（較緩）。

觀念

考前提醒
- 10°C/km只適用未飽和空氣塊自己升降，不要跟對流層「平均環境遞減率」6.5°C/km搞混——一個是空氣塊自己的變化率，一個是固定地點測得的環境剖面。

整理
類型原理例子

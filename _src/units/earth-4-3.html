風與三種水平作用力

  1. 空氣受外力作用而運動，就是風。
  2. 垂直方向：氣壓梯度力（往上）與重力大致平衡，所以大氣不容易有劇烈的垂直運動。
  3. 本單元說的「風」都是水平方向，受三種力影響：氣壓梯度力、科氏力、摩擦力。

氣壓梯度力

  1. 風向：空氣被氣壓梯度力推著，由高壓流向低壓。
  2. 風速：單位距離內氣壓差愈大（等壓線愈密），氣壓梯度力愈大，風速愈快。
  3. 方向恆垂直等壓線，由高壓指向低壓。
{{FIG_pgf}}

科氏力

  1. 地球自轉，使運動中的物體相對地面往右或往左偏移；造成偏移的「力」叫科氏力，是一種假想力。
  2. 緯度愈高，科氏力愈大：兩極最大、赤道為 0。
  3. 風速愈快，科氏力愈大；空氣靜止就沒有科氏力。
  4. 科氏力永遠和風向垂直：北半球指向運動方向的右方，南半球指向左方。
{{FIG_coriolis}}
觀念

考前提醒
- 科氏力和運動方向垂直 → 只改變風向，不改變風速。
- 赤道附近科氏力 ≈ 0，所以颱風不會在赤道上生成。

摩擦力

  1. 近地面的風受地表摩擦而變慢。
  2. 風速變慢 → 科氏力變小 → 偏轉角度變小（間接影響風向）。
  3. 摩擦力方向與風向相反。

地轉風與近地面的風

整理：地轉風 vs 近地面的風（北半球）
地轉風近地面的風
位置高空（約1公里以上），摩擦力很小近地表
受力氣壓梯度力、科氏力氣壓梯度力、科氏力、摩擦力
形成過程空氣加速 → 科氏力漸增 → 往右偏轉 90°，氣壓梯度力＝科氏力（方向相反）摩擦使風速低，科氏力不夠大，偏不到 90°
風向平行等壓線斜穿等壓線、偏向低壓，夾角 θ 一般不超過 30°
觀念

考前提醒
- 摩擦力愈大 → 風速愈慢 → 科氏力愈小 → 夾角 θ 愈大：陸地上的 θ 比海洋大。
- 白貝羅定律（背風而立，北半球高壓在右、低壓在左）在海上、高空最準，陸地上因摩擦會有誤差。

三步驟判斷風向

{{FIG_steps}}
  1. 找出該點附近兩條等壓線的走向。
  2. 畫氣壓梯度力：垂直等壓線，由高壓指向低壓。
  3. 北半球往右偏：地轉風偏 90°（平行等壓線）；地面風偏約 60～75°（和等壓線夾 15～30°）。
觀念

考前提醒
- 風向是「從哪裡吹來」：往西南吹的風叫東北風。
- 南半球三步驟相同，只是第 3 步改成往左偏。

高壓與低壓

{{FIG_highlow}}
整理
高壓（反氣旋）低壓（氣旋）
地面氣流輻散：北半球順時針旋出；南半球逆時針輻合：北半球逆時針旋入；南半球順時針
中心垂直氣流下沉（高空輻合）上升（高空輻散）
天氣下沉增溫、不易飽和 → 晴朗上升降溫、容易飽和 → 雲雨
觀念

口訣：右手法則
- 大拇指＝垂直氣流（朝上＝上升、朝下＝下沉），四指彎曲方向＝旋轉方向。
- 北半球用右手、南半球用左手。例：南半球高壓 → 左手、拇指朝下 → 四指是逆時針。

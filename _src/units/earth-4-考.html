考點 1：氣壓與空氣質量

  1. 氣壓是單位面積上方空氣柱的重量；高度愈高，頭頂剩下的空氣愈少，所以氣壓愈低。
  2. 低空空氣較密，因此相同高度差內，低空的氣壓降幅通常比高空大。標準氣壓約 1013 hPa，也等於 76 cmHg。
  3. 某高度以上的空氣重量占比＝該高度氣壓÷地面氣壓；以下占比＝（地面氣壓－該高度氣壓）÷地面氣壓，因為氣壓差代表兩高度之間空氣的重量。
  4. 讀圖先確認高度、氣壓的座標與單位，再用同一張圖的讀值計算。
這樣考

題目通常長這樣
- 給氣壓高度圖，問變化率或某高度以下的空氣占比。
- 看到「上方空氣柱重量」就先分辨以上或以下。
常見陷阱
- 高空氣壓仍下降，但空氣稀薄，等高度的降幅較小；不要把以上占比當以下占比。

考點 2：大氣分層與溫度成因

  1. 依溫度由下往上分為對流層、平流層、中氣層、增溫層；平均溫度趨勢依序為降、升、降、升。
  2. 對流層主要由受太陽加熱的地表加熱，因此愈往上通常愈冷；水氣與天氣變化主要集中在這裡。
  3. 平流層的臭氧吸收紫外線，使上部增溫、結構較穩定；臭氧是微量氣體，水氣通常比近地面少。
  4. 增溫層氣體吸收高能紫外線和 X 射線而升溫；但空氣稀薄，溫度計的讀數也受日照及散熱影響。
  5. 電離層橫跨中氣層上部與增溫層，可影響部分無線電波傳播；它依電離狀態命名，與溫度分層不同。
這樣考

題目通常長這樣
- 給溫度與高度圖，辨認分層、熱源及現象。
- 看到臭氧、紫外線、電離或高空溫度計，先確認所在高度與作用。
常見陷阱
- 臭氧集中不代表比氧氣多；氣體溫度高，也不能直接當成溫度計讀數。

考點 3：露點與相對溼度

  1. 飽和是空氣中的實際水氣壓達到該氣溫的飽和水氣壓；氣溫愈高，飽和水氣壓愈大。
  2. 露點是水氣壓不變時，空氣降溫到飽和的溫度；露點愈高，代表實際水氣壓愈高。
  3. 相對溼度＝實際水氣壓÷當時氣溫的飽和水氣壓×100%；它比較的是距離飽和有多近。
  4. 比較氣溫與露點圖時，差距愈小通常愈接近飽和；若實際水氣變化不大，清晨氣溫低時相對溼度通常較高。
這樣考

題目通常長這樣
- 給各地氣溫、露點表，或一天中兩條溫度曲線，分別比較水氣多寡與相對溼度。
- 看到「最接近飽和」先看氣溫與露點差距；問實際水氣先看露點。
常見陷阱
- 水氣多不等於相對溼度高，因為相對溼度還要看當時氣溫。

{{Q7}} {{Q8}} {{Q9}} {{Q10}}

記住：露點看實際水氣，相對溼度還要看氣溫。

考點 4：乾溼球溫度計

  1. 乾球直接測氣溫；溼球包有溼紗布，水蒸發吸熱，因此溼球讀數不高於乾球。
  2. 空氣愈乾燥，水愈容易蒸發，溼球降溫愈多，所以乾溼球溫差通常愈大。
  3. 未飽和時乾球溫度＞溼球溫度＞露點；飽和時三者相等，因為水不再淨蒸發。
  4. 飽和時相對溼度都是 100%，但溫度較高的飽和空氣仍可有較多水氣。
這樣考

題目通常長這樣
- 比較兩地或兩天的乾球、溼球與露點，判斷氣溫、水氣或溼度。
- 看到溼紗布先想蒸發吸熱；看到兩球等溫先判斷是否飽和。
常見陷阱
- 氣溫不是兩球平均；相對溼度相同也不代表實際水氣相同。

{{Q11}} {{Q12}} {{Q13}}

記住：乾球量氣溫，乾溼球差距反映蒸發與溼度。

考點 5：雲、霧、露、霜的形成

  1. 水氣達飽和可經降溫或增加水氣；自然界常由降溫達飽和，再凝結成水滴或凝華成冰晶。
  2. 高空懸浮的水滴或冰晶是雲，接近地面的叫霧；附著物體表面的液態水是露，冰晶是霜。
  3. 空氣中的氣膠可作凝結核，幫助水氣聚集；冷物表面若低於周圍空氣的露點，水氣可能在表面凝結。
  4. 地面輻射冷卻、暖溼空氣流過冷海面，或氣流受熱、地形及輻合抬升，都可能使空氣冷卻成雲霧；下沉則壓縮增溫，不易凝結。
這樣考

題目通常長這樣
- 給飽和曲線、冷鏡片或氣流運動情境，問哪種途徑容易凝結。
- 看到迎風坡、冷海面、地面輻合或高壓下沉，先判斷空氣升降與冷暖。
常見陷阱
- 雲與霧主要差在位置；露與霜附著表面，不要只憑「有水氣」就判定凝結。

{{Q14}} {{Q15}} {{Q16}} {{Q17}}

記住：先看空氣是否冷卻至飽和，再看水滴或冰晶的位置。

考點 6：絕熱冷卻與空氣塊上升、翻山

  1. 絕熱指空氣塊不與環境交換熱量；上升時外界氣壓降低，空氣塊膨脹作功而降溫，下沉則壓縮升溫。
  2. 未飽和上升通常以乾絕熱率約 10°C／公里降溫；題目若給露點每公里下降 2°C，兩者差距每公里縮小 8°C，直到相等而成雲。
  3. 飽和後水氣凝結釋放潛熱，部分抵銷降溫，所以溼絕熱降溫較慢；用題目指定的每公里降溫值，飽和時氣溫與露點相等。
  4. 翻山時分段計算：先算成雲高度，再算飽和上升；若水分已降落，背風坡下沉依未飽和的乾絕熱率增溫。
  5. 環境平均氣溫遞減率是不同高度的環境氣溫差，不是空氣塊的絕熱率；題目給哪一種就用哪一種。
這樣考

題目通常長這樣
- 給山高、山腳氣溫與露點，求雲底、山頂或背風坡溫度。
- 看到「不與環境交換熱量」，先判斷起點是否飽和；氣壓圖則先讀高度。
常見陷阱
- 不可整趟只用一種遞減率；問雲底要找剛達飽和的位置，不是所有已在雲內的位置。

{{Q18}} {{Q19}} {{Q20}} {{Q21}}

考點 7：風的三種力與判斷風向

  1. 氣壓梯度力垂直等壓線，由高壓指向低壓；等壓線愈密，梯度力通常愈大。
  2. 科氏力使運動中的空氣在北半球向前進方向右偏，且垂直風向；同緯度下風速愈快，科氏力愈大。
  3. 高空摩擦小，地轉風的梯度力與科氏力平衡，風平行等壓線；北半球背對風來向時，低壓在左。
  4. 地面摩擦力與風向相反，會減慢風速及科氏力，因此風斜穿等壓線吹向低壓；摩擦愈大，穿越角度通常愈大。
  5. 風向按風的來向命名：例如北風是由北往南吹；圖上箭頭若表示流動方向，讀名稱前要先反過來。
這樣考

題目通常長這樣
- 給等壓線和方向箭頭，問梯度力、科氏力或地面與高空風向。
- 看到海陸摩擦比較，先比較風速，再比較科氏力。
常見陷阱
- 梯度力指向低壓，但風不一定直接吹向低壓；風名是來向。

{{Q22}} {{Q23}} {{Q24}} {{Q25}}

記住：先由高壓指向低壓，再依半球與摩擦判斷風。

考點 8：冷熱與氣壓：熱力環流

  1. 同氣壓下，冷空氣密度較大，因此同樣高度內包含的空氣較重，氣壓隨高度下降較快，等壓面較密。
  2. 暖氣柱膨脹，等壓面間距較大；在理想熱力環流中，近地面暖區空氣上升、形成低壓，冷區下沉、形成高壓。
  3. 環流的近地面氣流由冷高壓吹向暖低壓，高空再流回；這是題設中的簡化環流，暖空氣不一定都上升。
  4. 地面氣壓相同，代表同面積上方空氣柱重量相同；較暖空氣的飽和水氣壓較高。
  5. 比較海陸風時也要看摩擦：相同緯度及梯度力下，陸地摩擦較大，風較慢、科氏力較小。
這樣考

題目通常長這樣
- 給冷暖氣柱的等壓面，或指定兩地氣壓相同，問密度、升降與風。
- 比較陸地和海洋風時，留意是否指定相同緯度與梯度力。
常見陷阱
- 不可只憑暖就斷定一定上升；氣壓相同時，也不可說某處整根氣柱較重。

考點 9：衛星雲圖與氣象雷達

  1. 可見光雲圖利用雲反射的陽光：雲愈白通常愈厚，需要日照；紅外線雲圖看雲頂溫度，通常愈白表示雲頂愈冷、愈高，日夜可用。
  2. 兩圖搭配可比較雲厚與雲頂高度；衛星雲圖呈現雲頂，不能直接判斷雲底。
  3. 雷達主動發射波並接收降水粒子回波；回波強通常與降雨較強有關，但相關不等於固定比例。
  4. 都卜勒雷達利用回波頻率變化判斷粒子沿雷達方向接近或遠離：接近時回波頻率較高。
  5. 比較雲圖與天氣圖時，先找雲帶、旋渦與高低壓，再看季風的迎風面；地面高壓通常下沉、少雲。
這樣考

題目通常長這樣
- 對照兩種衛星雲圖，或比較雷達回波、雨量及地面天氣圖。
- 看到都卜勒，先判斷降水粒子相對雷達是接近還是遠離。
常見陷阱

{{Q29}} {{Q30}} {{Q31}} {{Q32}}

記住：可見光看厚、紅外線看雲頂，雷達看降水與運動。

考點 10：天氣圖、鋒面與氣旋

  1. 等壓線連接同氣壓位置；往中心氣壓升高是高壓，降低是低壓。北半球近地面高壓順時針向外吹、下沉；低壓逆時針向內吹、上升。
  2. 測站符號的圓圈表示雲量，風桿長線指向風的來向；氣壓簡寫省略前面的 9 或 10 與小數點，要配合附近等壓線還原。
  3. 冷鋒是冷空氣推進暖空氣，三角形尖端指移動方向；暖鋒用半圓，滯留鋒則是半圓和三角形分列兩側。
  4. 冷鋒通常較快，追上暖鋒可形成囚錮鋒；北半球溫帶氣旋的低壓中心連接冷、暖鋒，兩鋒之間可有暖區。
  5. 熱帶氣旋形成於低緯暖海面，通常沒有鋒面；溫帶氣旋形成於中緯度冷暖氣團交界，水平尺度通常較大。
這樣考

題目通常長這樣
- 讀測站符號、等壓線與鋒面，判斷氣壓、風向和各區天氣。
- 看到三角形先看尖端；看到氣旋先找中心和鋒面。
常見陷阱
- 風桿指來向，與氣流前進方向相反；不能只憑單張天氣圖斷定一定有濃霧。

考點 11：臺灣的季節天氣與雨型

  1. 冬季大陸冷高壓增強，臺灣常吹東北季風；北部、東北部迎風，較易陰雨。
  2. 5～6 月鋒面常停留在華南到臺灣附近，形成梅雨；夏季常見大陸低壓、太平洋高壓及偏南風，也可能有午後雷陣雨或颱風。
  3. 夏季陸地因比熱較小而升溫快，較暖的陸地容易形成熱低壓；太平洋高壓中心則盛行下沉，不利雷雨。
  4. 雷雨通常需要充足水氣與旺盛上升氣流；冷乾氣團或高壓下沉區較不利形成。
  5. 讀降雨表時，月平均＝全年雨量÷12；某月降雨日平均＝月雨量÷降雨日數。雨跡日數若已包含在降雨日數內，要排除時才相減。
這樣考

題目通常長這樣
- 由冷高壓、鋒面、太平洋高壓或颱風配對季節；也可能比較月雨量和雨日。
- 問雷雨先看水氣和上升氣流；問平均先確認分母。
常見陷阱
- 雨日多不代表每個雨日的平均雨量大；一年的統計也不代表每年完全相同。

第3章 反應速率

3-3影響反應速率的因素（I）本質、濃度、接觸面積、溫度

本單元 23 題

重點整理

一、反應物的本質與反應速率

化學反應有鍵的破壞與生成，而化學鍵的特性取決於物質本質，所以反應物的本質會影響速率。

室溫下的一般法則
1. 不涉及鍵破壞的反應較快：H＋ ＋ OH− → H2O；Ag＋ ＋ Cl− → AgCl(s)
2. 涉及共價鍵破壞愈多的反應愈慢：
- 5Fe2＋ ＋ MnO4− ＋ 8H＋ → …（快）：Fe2＋ → Fe3＋ 只有電子轉移
- 5C2O42− ＋ 2MnO4− ＋ 16H＋ → 10CO2 ＋ …（慢）：還要打斷 C−C 鍵

常溫下較快的反應
1. H＋ ＋ OH− → H2O：中和，極快
2. Ag＋ ＋ Cl− → AgCl(s)：沉澱，快（離子要排成晶格，比中和略慢）
3. Cu2＋ ＋ 4NH3 → Cu(NH3)42＋：錯離子只形成鍵，快
4. Ce4＋ ＋ Fe2＋ → Ce3＋ ＋ Fe3＋：只有電子轉移（兩者互斥，比中和慢）
5. 5Fe2＋ ＋ MnO4− ＋ 8H＋ → 5Fe3＋ ＋ Mn2＋ ＋ 4H2O
6. P4(s) ＋ 5O2 → P4O10：白磷很不安定，燃燒活化能低
7. 2NO ＋ O2 → 2NO2：常溫約 7～8 秒完成
8. H2 ＋ F2 → 2HF：室溫暗處也會爆炸
9. HCl(g) ＋ NH3(g) → NH4Cl(s)

常溫下較慢的反應
1. 有機反應（如酯化）：要破壞較多共價鍵，活化能較高。
2. 燃燒反應（如 CH4 ＋ 2O2）：破壞多個強共價鍵，常溫幾乎不反應。

整理
  1. 室溫下反應速率：中和 ＞ 沉澱 ＞ 氧化還原 ＞ 有機反應 ＞ 燃燒反應
  2. H2(g) ＋ X2(g) → 2HX(g) 的速率：F2 ＞ Cl2 ＞ Br2 ＞ I2

二、濃度、接觸面積與反應速率

1. 勻相與非勻相反應

  • 勻相反應：在同一個相中進行。H＋(aq) ＋ OH−(aq)；NH3(g) ＋ HCl(g)
  • 非勻相反應：在兩種以上不同相中進行。CaCO3(s) ＋ 2HCl(aq) → …

2. 反應物濃度

  • 濃度增加 → 碰撞頻率增加 → 速率加快。
  • 勻相反應增加濃度的方法：水溶液 → 增加溶質或減少溶劑；氣相 → 增加反應物或縮小體積。

3. 接觸面積

  • 非勻相反應發生在相的界面，增加接觸面積可加快速率。
  • 方法：
    1. 粉碎：邊長等分為 n 段，可切成 n3 個小正方體，總表面積變為 n 倍。
    2. 攪拌：把飽和的溶液散開，讓新鮮溶劑接觸溶質；撥動炭火增加與氧接觸。

三、溫度與反應速率

1. 溫度的效應

  • 定性：升高溫度，不論吸熱或放熱、正向或逆向反應，速率都變快。
  • 定量：室溫附近每升高 10 ℃，速率約增為 2 倍。

2. 升溫使速率加快的原因

  1. 主因：分子平均動能變大，超過低限能的分子數增加，有效碰撞增加。
  2. 次因：分子運動變快，碰撞頻率增加。
觀念

25 ℃ → 35 ℃ 速率加倍：
- 超過低限能的分子數約變為 2 倍 → 主因
- 碰撞頻率 ∝ √T：√(308/298) ≈ 1.02，只增加 2%，無法解釋加倍 → 次因

3. 溫度能改變 / 不能改變的

可改變 不可改變
分子動能分布曲線 活化能
反應熱 反應途徑（反應機構）
正、逆反應速率（不等量改變）
正、逆反應速率常數（不等量改變）
化學平衡、平衡常數
觀念

活化能較大的反應，速率受溫度影響較大。
例：熱 ＋ A ＋ B ⇌ C ＋ D（吸熱，正反應活化能 ＞ 逆反應活化能）
- 升溫：正反應變 m 倍、逆反應變 n 倍 ⇒ m ＞ n ＞ 1
- 降溫：⇒ 1 ＞ n ＞ m
